# PornWeb

Self-hosted media library (FastAPI + Vue). Scan local/NFO packs, browse, and stream.

## Stack

- Backend: FastAPI, SQLite
- Frontend: Vue 3, Vite, Element Plus

## Quick start

See `DEPLOY.md` and `setup.sh`. Copy `backend/.env.example` to `backend/.env` and change `SECRET_KEY`.

Do not commit `.env`, `venv`, or media files.
